# Trade-offs

| Constraint | Strategy | Impact |
|---|---|---|
| Latency | Granular Decomposition | Increases execution latency but ensures predictability. |
| Reasoning Depth | Context Isolation | Prevents context window explosion, massively increasing logical depth per step. |
| Token Cost | Orchestrated Delegation | Reduces tokens by sending only relevant schemas to specialized agents. |
